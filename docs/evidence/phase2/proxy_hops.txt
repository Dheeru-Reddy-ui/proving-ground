Reading: Render's proxies append to the header (the spoofed entry is kept and three are added),
so the client's own address is the 3rd entry from the right and anything further left is
client-controlled. PG_TRUSTED_PROXY_HOPS=3 (pg_api/middleware.py client_ip).

Caveat: measured from one client network on one day. If Render's chain ever shrinks, a request
with fewer than 3 entries falls back to the peer address (stricter, never looser); a spoofed
entry could then be read as the client, so re-measure after Render changes its edge.
