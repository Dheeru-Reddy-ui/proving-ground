# Character, theme and power-up selection

Before a run, the main menu lets the player choose who runs, where, and with which power-up.

- CHAR-1: A new game owns the character Trash Cat and the Day theme, and both are selected.
- CHAR-2: The main menu shows the name of the selected character.
- CHAR-3: The character arrows cycle only through characters the player owns.
- CHAR-4: A character bought in the store appears in the character selection straight away.
- CHAR-5: The character selected in the main menu is the one that runs when the run starts.
- CHAR-6: The theme arrows cycle only through themes the player owns, and the run takes place in the selected theme.
- CHAR-7: Accessories can be chosen only from those the player owns for the selected character. [confirm]
- CHAR-8: The power-up selector shows only power-ups the player owns, with how many of each.
- CHAR-9: Starting a run with a power-up equipped uses up one of that power-up from the inventory and gives it to the player for that run.
- CHAR-10: Starting a run with no power-up equipped leaves the inventory unchanged.
