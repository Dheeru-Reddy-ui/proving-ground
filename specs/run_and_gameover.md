# Run and game over

A run is one attempt on the endless track; it ends on the game-over screen.

- RUN-1: Starting a run from the main menu begins gameplay after a short countdown.
- RUN-2: During a run the screen shows the score, the distance, the score multiplier, the coins and premium collected in this run, and the remaining lives.
- RUN-3: Picking up a coin adds one to the run's coin count; picking up premium currency adds one to the run's premium count.
- RUN-4: The player starts each run with three lives and loses one each time they hit an obstacle.
- RUN-5: Pausing stops the run; resuming continues the same run where it stopped.
- RUN-6: Quitting from the pause menu ends the run and returns to the main menu.
- RUN-7: When the last life is lost, the player may continue by spending 3 premium, but only if they have at least 3.
- RUN-8: Continuing for premium takes exactly 3 premium from the player's balance and lets the same run go on.
- RUN-9: Declining to continue ends the run and shows the game-over screen.
- RUN-10: The game-over screen shows the run's final score.
- RUN-11: Coins and premium collected during a run are added to the player's balances.
- RUN-12: From the game-over screen the player can run again, open the store, open the leaderboard or return to the main menu.
- RUN-13: A run's score is recorded on the leaderboard when it ranks among the high scores. [confirm]
- RUN-14: On a new game the first run is a tutorial that teaches the moves; the main menu is fully available once the tutorial is completed. [confirm]
